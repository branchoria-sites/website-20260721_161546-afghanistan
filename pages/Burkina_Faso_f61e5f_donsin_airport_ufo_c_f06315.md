## Introduction

The alleged UFO sighting above the Ouagadougou–Donsin airport project is one of the few modern claims associated with [Burkina Faso]({{ 'what-is-really-behind-burkina-fasos-ufo/' | relative_url }}), but it is also one of the weakest from an evidential standpoint. Social-media posts asserted that an unusual object hovered above the airport construction site before disappearing. However, no publicly verifiable original footage, exact observation time, named witnesses, independent photographs or official investigation has emerged. As a result, the incident cannot be assessed in the same way as better-documented unidentified aerial phenomena (UAP) cases.

Rather than providing evidence of an unexplained craft, the Donsin claim illustrates how contemporary UFO stories can spread rapidly online despite lacking the basic information needed for verification. It therefore serves as a useful case study in evaluating evidence quality within Burkina Faso's limited public UFO record.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.boad.org/en/our-publications/projects/construction-of-the-ouagadougou-donsin-international-airport-in-burkina-faso/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: boad.org">[La BOAD]</a><span class="citation-popover" role="note"><span class="citation-popover-source">boad.org</span><span class="citation-popover-snippet">Open source on boad.org.</span></span></span>

## What Was Seen Above the Donsin Airport Site?

The claim circulated primarily through social-media posts stating that an unidentified object had been observed over the Donsin airport project near Ouagadougou. The descriptions generally suggested that the object remained visible for several minutes before disappearing.

## What the Social-Media Posts Actually Claimed

The available posts generally shared the same broad narrative:


<div class="content-enhancement content-enhancement--insight-grid" markdown="1">

* an unidentified object appeared above the Donsin airport area;
* observers reportedly watched it for several minutes;
* it then disappeared;
* the event was presented as mysterious or potentially extraterrestrial.

</div>

Notably absent are the details that usually allow independent verification. Even seemingly simple questions remain unanswered:


<div class="content-enhancement content-enhancement--insight-grid" markdown="1">

* Was the object moving or stationary?
* Was it seen during daylight, twilight or darkness?
* Was it recorded by multiple people?
* Was it viewed from inside the construction site or elsewhere?
* Were aircraft operating nearby at the time?

</div>

Because later posts largely repeat earlier ones without adding new primary evidence, the claim has accumulated visibility rather than documentation.

## Missing Data That Prevents Identification

The Donsin report demonstrates why many internet UFO claims remain impossible to classify. Investigators normally compare observations against several independent datasets, but almost every required input is missing here.

### No verified timestamp

Without an exact observation time, investigators cannot compare the sighting with:


<div class="content-enhancement content-enhancement--phrase-pills" markdown="1">

* scheduled aircraft movements;
* military or civilian flight activity;
* satellite passes;
* astronomical objects;
* meteor records;
* weather observations.

</div>

A difference of only a few minutes can completely change which conventional explanations are plausible.

### No original recording

Compressed copies circulating on social media remove valuable information such as:


<div class="content-enhancement content-enhancement--phrase-pills" markdown="1">

* camera model;
* exposure settings;
* GPS information;
* original resolution;
* frame sequence.

</div>

Without the source file, digital artefacts or editing cannot be evaluated.

### No corroborating witnesses

No independently interviewed witnesses have publicly described the event. A single repeated social-media narrative is far less valuable than several independent accounts recorded shortly after the observation.

These gaps mean the object cannot honestly be classified as either extraordinary or ordinary. It simply remains unidentified because the available evidence is insufficient.

## Aircraft, Drones and Misleading Airport Imagery

The location itself makes conventional explanations especially important.

Donsin is the site of Burkina Faso's long-running replacement international airport project. The planned airport includes a 3,500-metre runway capable of handling wide-body aircraft and is intended eventually to replace Ouagadougou's existing international airport. Large construction projects of this kind involve survey equipment, cranes, construction lighting, aircraft, helicopters and increasingly the use of drones for mapping and inspection.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.boad.org/en/our-publications/projects/construction-of-the-ouagadougou-donsin-international-airport-in-burkina-faso/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: boad.org">[La BOAD]</a><span class="citation-popover" role="note"><span class="citation-popover-source">boad.org</span><span class="citation-popover-snippet">Open source on boad.org.</span></span></span>

Even if no aircraft were yet operating from the unfinished runway at the reported time, nearby aviation activity, construction equipment or aerial survey operations remain plausible possibilities that cannot be excluded.

The location has also been associated with misleading visual content unrelated to UFOs. Africa Check has documented multiple instances in which photographs supposedly showing airport developments in Burkina Faso were actually images from entirely different locations, including Dubai. While those fact-checks do not disprove the UFO claim itself, they demonstrate that inaccurate imagery linked to airport infrastructure has already circulated widely online.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://africacheck.org/fr/fact-checks/meta-programme-fact-checks/burkina-faso-images-hors-contexte-aeroport-bobo-Dioulasso" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: africacheck.org">[Africa Check]</a><span class="citation-popover" role="note"><span class="citation-popover-source">africacheck.org</span><span class="citation-popover-snippet">Africa CheckBurkina Faso: ces images ne montrent pas l’évolution des travaux de construction de l&#x27;aéroport international de Bobo Dioulas...</span></span></span>

That broader pattern matters because it shows how impressive-looking visuals can become detached from their original context and later be reused to support unrelated narratives.

## Why the Claim Remains Unverified

No evidence has emerged showing that Burkinabè aviation authorities, airport management or government agencies investigated the reported object. Likewise, there are no publicly available radar records, air traffic communications or technical reports connected with the claim.

Equally important, there is no evidence demonstrating that ordinary explanations were systematically ruled out. The absence of an explanation is not itself evidence of an extraordinary event. It more often reflects the absence of sufficient observational data.

From an evidence-based perspective, the most accurate classification is therefore:


<div class="content-enhancement content-enhancement--insight-grid" markdown="1">

* **Reported:** yes.
* **Documented with original evidence:** no.
* **Officially investigated:** no publicly confirmed investigation.
* **Conventional explanations eliminated:** no.
* **Evidence for an anomalous craft:** insufficient.

</div>

## What the Donsin Case Contributes to Burkina Faso's UFO Record

Within Burkina Faso's broader UFO history, the Donsin airport story is significant not because it presents compelling evidence of an unidentified craft, but because it illustrates the modern dynamics of online UFO reporting.

Unlike historical cases supported by extensive witness testimony, photographs or official files, the Donsin report consists primarily of repeated social-media claims without an accompanying evidential record. It therefore highlights the distinction between a widely shared story and a well-documented incident.

As a result, the Donsin airport claim is best understood as an example of an **unverified modern report** rather than a confirmed unidentified aerial phenomenon. Until original recordings, identifiable witnesses, precise timing and independent corroboration become available, there is no reliable basis for determining whether the object represented an aircraft, drone, atmospheric phenomenon, camera artefact or something genuinely unexplained.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.boad.org/en/our-publications/projects/construction-of-the-ouagadougou-donsin-international-airport-in-burkina-faso/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: boad.org">[La BOAD]</a><span class="citation-popover" role="note"><span class="citation-popover-source">boad.org</span><span class="citation-popover-snippet">Open source on boad.org.</span></span></span>

    var select = section.querySelector('[data-ebay-market-select]');
    if (select) {
      return Array.prototype.slice.call(select.options)
        .map(function (option) { return option.value; })
        .filter(function (marketId) { return !!markets[marketId]; });
    }
    return Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]'))
      .map(function (button) { return button.getAttribute('data-ebay-market-button'); })
      .filter(function (marketId) { return !!markets[marketId]; });
  }
  function applyMarket(section, marketId, persist) {
    var available = availableMarkets(section);
    if (available.indexOf(marketId)< 0) marketId = available[0] || defaultMarket;
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-localized-link]')).forEach(function (link) {
      var query = link.getAttribute('data-ebay-query') || '';
      var reference = link.getAttribute('data-ebay-reference') || '';
      link.setAttribute('href', buildUrl(query, reference, marketId));
    });
    var select = section.querySelector('[data-ebay-market-select]');
    if (select && available.indexOf(marketId) >= 0) select.value = marketId;
    var selectedText = marketId;
    if (select && select.selectedIndex >= 0) selectedText = select.options[select.selectedIndex].text;
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-selected-market-label]')).forEach(function (label) {
      label.textContent = selectedText;
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-selected-market-flag], [data-ebay-trigger-market-flag]')).forEach(function (flag) {
      flag.className = flagClass(marketId);
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-trigger-market-label]')).forEach(function (label) {
      label.textContent = selectedText;
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-domain-label]')).forEach(function (label) {
      label.textContent = domainLabel(marketId);
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-option]')).forEach(function (button) {
      button.setAttribute('aria-selected', button.getAttribute('data-ebay-market-option') === marketId ? 'true' : 'false');
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]')).forEach(function (button) {
      var active = button.getAttribute('data-ebay-market-button') === marketId;
      button.setAttribute('aria-pressed', active ? 'true' : 'false');
    });
    section.setAttribute('data-ebay-selected-market', marketId);
    if (persist) {
      try { if (window.localStorage) localStorage.setItem('phoenix-ebay-market', marketId); } catch (err) {}
    }
    closeMenu(section);
  }
  sections.forEach(function (section) {
    if (section.getAttribute('data-ebay-localized-init') === '1') return;
    section.setAttribute('data-ebay-localized-init', '1');
    var available = availableMarkets(section);
    var marketId = defaultMarket;
    if (window.PhoenixAffiliateLocation && window.PhoenixAffiliateLocation.inferMarket) {
      marketId = window.PhoenixAffiliateLocation.inferMarket(available, {
        storageKey: 'phoenix-ebay-market',
        defaultMarket: defaultMarket
      });
    } else if (available.indexOf(defaultMarket)< 0) {
      marketId = available[0] || defaultMarket;
    }
    var select = section.querySelector('[data-ebay-market-select]');
    if (select) {
      select.addEventListener('change', function () {
        applyMarket(section, select.value, true);
      });
    }
    var trigger = section.querySelector('[data-ebay-market-trigger]');
    var menu = section.querySelector('[data-ebay-market-menu]');
    if (trigger && menu) {
      trigger.addEventListener('click', function (event) {
        event.stopPropagation();
        var expanded = trigger.getAttribute('aria-expanded') === 'true';
        menu.hidden = expanded;
        trigger.setAttribute('aria-expanded', expanded ? 'false' : 'true');
        var picker = trigger.closest('.fr-ebay-market-picker');
        if (picker) picker.classList.toggle('fr-ebay-market-picker--open', !expanded);
      });
      Array.prototype.slice.call(menu.querySelectorAll('[data-ebay-market-option]')).forEach(function (button) {
        button.addEventListener('click', function (event) {
          event.stopPropagation();
          applyMarket(section, button.getAttribute('data-ebay-market-option'), true);
        });
      });
      document.addEventListener('click', function () { closeMenu(section); });
    }
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]')).forEach(function (button) {
      button.addEventListener('click', function () {
        applyMarket(section, button.getAttribute('data-ebay-market-button'), true);
      });
    });
    applyMarket(section, marketId, false);
  });
})();
</script>
