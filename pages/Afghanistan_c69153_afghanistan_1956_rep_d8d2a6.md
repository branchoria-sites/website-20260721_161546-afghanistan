## Introduction

The January 1956 [Afghanistan]({{ 'what-does-afghanistans-ufo-record/' | relative_url }}) UFO reports occupy a distinctive place in the country's UFO history because they are the earliest known Afghan sightings preserved in the declassified files of the US Air Force's Project Blue Book. They are also frequently overstated. Modern retellings often focus on a dramatic claim that a metallic flying saucer landed in northern Afghanistan, while overlooking the fact that the official record is only a few pages long, consists largely of relayed reports rather than direct investigation, and ends without confirming that any object was ever found. The surviving evidence therefore establishes that unusual reports circulated within Afghanistan in early 1956, but it does not establish that an extraordinary craft was recovered or even observed under verifiable conditions.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.archives.gov/research/military/air-force/ufos" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: archives.gov">[National Archives]</a><span class="citation-popover" role="note"><span class="citation-popover-source">archives.gov</span><span class="citation-popover-title">National Archives Project BLUE BOOK</span><span class="citation-popover-snippet">National ArchivesProject BLUE BOOK - Unidentified Flying Objects &#124; National ArchivesJune 25, 2024...</span><span class="citation-popover-meta">Published: June 25, 2024</span></span></span>

## How the reports reached Project Blue Book

Unlike many domestic American Blue Book cases, the Afghanistan file did not begin with Air Force investigators interviewing eyewitnesses. Instead, the information travelled through diplomatic and military reporting channels.

The surviving documents indicate that the US Air Attaché in Kabul forwarded material derived from Afghan official communications, including a press release issued by the Bakhtar News Agency. That material was transmitted to Wright-Patterson Air Force Base, where Project Blue Book maintained its central case files. The chain of reporting therefore passed through several layers before reaching American analysts, reducing opportunities to verify details directly.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.govweird.com/topics/ufo/project-blue-book/year/1956" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: govweird.com">[govweird]</a><span class="citation-popover" role="note"><span class="citation-popover-source">govweird.com</span><span class="citation-popover-snippet">1956 Project Blue Book UFO Sightings · govweird · govweird...</span></span></span>

The reports described sightings from multiple locations rather than one isolated incident. Among the places named were Behsud, Kotal Mulla Yakoub, Shala, Durbaba and areas of Herat Province. Witnesses reportedly described both round and square-shaped "flying saucers", suggesting either multiple unrelated observations or a rapidly spreading wave of reports rather than a single trackable object. The surviving file does not contain precise observation times, weather information, flight paths or individual witness statements that would allow investigators to compare the reports systematically.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.govweird.com/topics/ufo/project-blue-book/year/1956" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: govweird.com">[govweird]</a><span class="citation-popover" role="note"><span class="citation-popover-source">govweird.com</span><span class="citation-popover-snippet">1956 Project Blue Book UFO Sightings · govweird · govweird...</span></span></span>

This distinction matters. The file documents what Afghan authorities reported to American officials, not what Project Blue Book independently established through field investigation.

## The alleged landed metallic object

The most remarkable element of the file concerns an alleged landing between Khanabad and Baghlan in the former Kataghan Province.

According to a message attributed to the provincial governor, a metallic object roughly 15 metres in circumference had landed and possessed small, thick glass windows around its upper edge. The report further stated that Afghan authorities hoped to transport the object to Kabul for examination by the Ministry of Defence but were uncertain whether suitable transport equipment existed. It also referred to an aerial search planned for the following day to confirm the information.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.govweird.com/topics/ufo/project-blue-book/year/1956" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: govweird.com">[govweird]</a><span class="citation-popover" role="note"><span class="citation-popover-source">govweird.com</span><span class="citation-popover-snippet">1956 Project Blue Book UFO Sightings · govweird · govweird...</span></span></span>

On its face, this description is extraordinary. If accurate, it would represent one of the most dramatic claims ever forwarded into the Blue Book system. Yet the surviving documentation immediately reveals its limitations:


<div class="content-enhancement content-enhancement--insight-grid" markdown="1">

* no photographs accompany the report;
* no physical measurements are recorded beyond the estimated size;
* no inspection report follows;
* no engineering assessment survives;
* no witness interviews are included;
* no later cable confirms that the object was located or transported.

</div>

In other words, the file preserves the existence of the claim, not evidence that the claim proved true.

## Why the case remained "insufficient data"

One of the most misunderstood aspects of the Afghanistan case is Project Blue Book's final classification.

The Air Force did **not** conclude that the reports represented an unknown craft after exhaustive investigation. Instead, the case received the designation **"Insufficient Data."** Within Blue Book's system, this meant investigators lacked enough reliable information to determine what had occurred. The classification reflected evidential weakness rather than confirmation of an unexplained phenomenon.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.archives.gov/research/military/air-force/ufos" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: archives.gov">[National Archives]</a><span class="citation-popover" role="note"><span class="citation-popover-source">archives.gov</span><span class="citation-popover-title">National Archives Project BLUE BOOK</span><span class="citation-popover-snippet">National ArchivesProject BLUE BOOK - Unidentified Flying Objects &#124; National ArchivesJune 25, 2024...</span><span class="citation-popover-meta">Published: June 25, 2024</span></span></span>

Several factors explain why the file could progress no further:


<div class="content-enhancement content-enhancement--metric" markdown="1">

* the information was second-hand by the time it reached American analysts;
* no original investigative material accompanied the diplomatic messages;
* there was no physical evidence available for examination;
* the reported recovery operation generated no documented follow-up in the surviving archive.

</div>

Consequently, the case never reached the stage where conventional explanations could be tested against detailed observations.

## What can and cannot be inferred today

Reassessment benefits from separating the historical record from later speculation.

What the documents support is relatively modest. They show that Afghan officials considered the reports sufficiently noteworthy to circulate them through official channels, that multiple locations were mentioned within a short period, and that one report described an alleged landed object in unusually specific terms. These facts make the case historically interesting within Afghanistan's limited UFO record.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.govweird.com/topics/ufo/project-blue-book/year/1956" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: govweird.com">[govweird]</a><span class="citation-popover" role="note"><span class="citation-popover-source">govweird.com</span><span class="citation-popover-snippet">1956 Project Blue Book UFO Sightings · govweird · govweird...</span></span></span>

What the documents do **not** demonstrate is equally important.

There is no surviving evidence that:


<div class="content-enhancement content-enhancement--insight-grid" markdown="1">

* a metallic craft was successfully recovered;
* American personnel examined such an object;
* Afghan authorities produced technical findings;
* additional classified reports confirmed the incident;<span class="citation-chip-wrap"><a class="citation-chip" href="https://www.archives.gov/foia/ufos.html" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: archives.gov">[Project BLUE BOOK]</a><span class="citation-popover" role="note"><span class="citation-popover-source">archives.gov</span><span class="citation-popover-snippet">National ArchivesProject BLUE BOOK - Unidentified Flying Objects &#124; National ArchivesJune 25, 2024</span></span></span> ok secretly solved the case but withheld the result.

## How reliable are the location details?

The geographical references themselves illustrate another difficulty.

Place names in the cables reflect English transliterations used in the 1950s, some of which differ from modern spellings. Administrative boundaries have also changed since the Kingdom of Afghanistan period. As a result, later writers sometimes struggle to identify precisely where every reported sighting occurred.

The landed-object report is generally associated with the area between Khanabad and Baghlan in what was then Kataghan Province, but even this location cannot be mapped with complete certainty from the surviving paperwork alone. The file therefore provides broad regional context rather than a precisely reconstructable incident scene.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.govweird.com/topics/ufo/project-blue-book/year/1956" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: govweird.com">[govweird]</a><span class="citation-popover" role="note"><span class="citation-popover-source">govweird.com</span><span class="citation-popover-snippet">1956 Project Blue Book UFO Sightings · govweird · govweird...</span></span></span>

## Why the 1956 reports still matter

Although the evidential quality is poor, dismissing the case entirely would overlook its historical significance.

Within Afghanistan's documented UFO chronology, the January 1956 reports remain the country's earliest substantial appearance in official American government records. They demonstrate that unusual aerial reports from Afghanistan entered Cold War intelligence channels and were considered worthy of filing within Project Blue Book's international case collection.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.archives.gov/research/military/air-force/ufos" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: archives.gov">[National Archives]</a><span class="citation-popover" role="note"><span class="citation-popover-source">archives.gov</span><span class="citation-popover-title">National Archives Project BLUE BOOK</span><span class="citation-popover-snippet">National ArchivesProject BLUE BOOK - Unidentified Flying Objects &#124; National ArchivesJune 25, 2024...</span><span class="citation-popover-meta">Published: June 25, 2024</span></span></span>

At the same time, reassessment shows that the case is often presented more dramatically than the documentation justifies. The surviving file records reports, rumours and official communications—not a verified recovery of an unknown craft. For historians, researchers and sceptics alike, its principal value lies in illustrating how extraordinary claims can persist in public memory despite a documentary record that remains remarkably brief, incomplete and ultimately inconclusive.

      var reference = link.getAttribute('data-ebay-reference') || '';
      link.setAttribute('href', buildUrl(query, reference, marketId));
    });
    var select = section.querySelector('[data-ebay-market-select]');
    if (select && available.indexOf(marketId) >= 0) select.value = marketId;
    var selectedText = marketId;
    if (select && select.selectedIndex >= 0) selectedText = select.options[select.selectedIndex].text;
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-selected-market-label]')).forEach(function (label) {
      label.textContent = selectedText;
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-selected-market-flag], [data-ebay-trigger-market-flag]')).forEach(function (flag) {
      flag.className = flagClass(marketId);
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-trigger-market-label]')).forEach(function (label) {
      label.textContent = selectedText;
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-domain-label]')).forEach(function (label) {
      label.textContent = domainLabel(marketId);
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-option]')).forEach(function (button) {
      button.setAttribute('aria-selected', button.getAttribute('data-ebay-market-option') === marketId ? 'true' : 'false');
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]')).forEach(function (button) {
      var active = button.getAttribute('data-ebay-market-button') === marketId;
      button.setAttribute('aria-pressed', active ? 'true' : 'false');
    });
    section.setAttribute('data-ebay-selected-market', marketId);
    if (persist) {
      try { if (window.localStorage) localStorage.setItem('phoenix-ebay-market', marketId); } catch (err) {}
    }
    closeMenu(section);

        storageKey: 'phoenix-ebay-market',
        defaultMarket: defaultMarket
      });

      marketId = available[0] || defaultMarket;
    }
    var select = section.querySelector('[data-ebay-market-select]');
    if (select) {
      select.addEventListener('change', function () {
        applyMarket(section, select.value, true);
      });
    }
    var trigger = section.querySelector('[data-ebay-market-trigger]');
    var menu = section.querySelector('[data-ebay-market-menu]');
    if (trigger && menu) {
      trigger.addEventListener('click', function (event) {
        event.stopPropagation();

        menu.hidden = expanded;
        trigger.setAttribute('aria-expanded', expanded ? 'false' : 'true');
        var picker = trigger.closest('.fr-ebay-market-picker');
        if (picker) picker.classList.toggle('fr-ebay-market-picker--open', !expanded);
      });
      Array.prototype.slice.call(menu.querySelectorAll('[data-ebay-market-option]')).forEach(function (button) {
        button.addEventListener('click', function (event) {
          event.stopPropagation();
          applyMarket(section, button.getAttribute('data-ebay-market-option'), true);
        });
      });
      document.addEventListener('click', function () { closeMenu(section); });
    }
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]')).forEach(function (button) {
      button.addEventListener('click', function () {
        applyMarket(section, button.getAttribute('data-ebay-market-button'), true);
      });
    });
    applyMarket(section, marketId, false);
  });
