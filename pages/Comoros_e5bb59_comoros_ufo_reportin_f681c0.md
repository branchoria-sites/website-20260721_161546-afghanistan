## Introduction

[Comoros]({{ 'what-do-we-really-know-about-comoros/' | relative_url }}) does not currently have a public, dedicated archive for unidentified aerial phenomena (UAP), formerly known as UFOs. That absence is significant because it means future reports are likely to remain scattered across personal accounts, social media posts or local conversations, making them difficult to investigate or compare. A reliable archive would not exist to prove extraordinary claims. Instead, its purpose would be to preserve evidence, test ordinary explanations first and create a transparent historical record that distinguishes confirmed facts from unresolved observations.



<img src="{{ "/assets/images/Comoros_e5bb59_comoros_ufo_reportin_f681c0-Illustration-1-dark.svg" | relative_url }}" alt="Reporting System illustration 1" data-theme-src-dark="{{ "/assets/images/Comoros_e5bb59_comoros_ufo_reportin_f681c0-Illustration-1-dark.svg" | relative_url }}" data-theme-src-light="{{ "/assets/images/Comoros_e5bb59_comoros_ufo_reportin_f681c0-Illustration-1-light.svg" | relative_url }}" loading="eager" decoding="sync" fetchpriority="high">

The strongest model for Comoros would be a small, evidence-based reporting system built around the country's existing aviation and meteorological institutions rather than a new specialist agency. NASA's independent UAP study concluded that the greatest obstacle to understanding unusual aerial reports is not a lack of theories but a lack of consistent, high-quality observations with proper metadata. The same principle applies even more strongly in Comoros, where no well-documented national case archive currently exists.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.nasa.gov/news-release/update-nasa-shares-uap-independent-study-report-names-director/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: nasa.gov">[NASA]</a><span class="citation-popover" role="note"><span class="citation-popover-source">nasa.gov</span><span class="citation-popover-title">UPDATE: NASA Shares UAP Independent Study Report; Names Director</span><span class="citation-popover-snippet">UPDATE: NASA Shares UAP Independent Study Report; Names Director - NASASeptember 14, 2023...</span><span class="citation-popover-meta">Published: September 14, 2023</span></span></span>

## Which aviation and weather records matter

A credible archive should not rely solely on witness testimony. Every case should be compared against objective records that may explain the observation.

The most useful sources would include:


<div class="content-enhancement content-enhancement--insight-grid" markdown="1">

* Civil aviation records for scheduled and known aircraft activity.
* Meteorological observations covering cloud conditions, storms, wind, visibility and atmospheric phenomena.
* Notices affecting air navigation.
* Astronomical information, including the positions of bright planets, the Moon and meteor showers.
* Satellite tracking information where publicly available.
* Space launch schedules and re-entry events.
* Local reports of drones, fireworks or military exercises if applicable.

</div>

Comoros already possesses an institutional foundation for this work through the National Agency for Civil Aviation and Meteorology (ANACM), whose responsibilities include civil aviation oversight and meteorological services in line with international aviation standards. While ANACM does not operate a UFO archive, its existing records would be among the most valuable sources for evaluating future reports.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://anacm-comores.com/presentation.php" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: anacm-comores.com">[Anacm Comores]</a><span class="citation-popover" role="note"><span class="citation-popover-source">anacm-comores.com</span><span class="citation-popover-title">Anacm Comores Présentation</span><span class="citation-popover-snippet">Anacm ComoresPrésentation - ANACM...</span></span></span>

For example, a bright moving object observed shortly after sunset might initially appear unusual. Cross-checking satellite passes, aircraft movements, atmospheric conditions and astronomical data could show that it matched a Starlink satellite train, Venus near the horizon or an aircraft reflecting sunlight. Cases that remain unexplained only after these checks would deserve closer examination.

## How cases should be classified and published

A reliable archive should avoid treating every unexplained report as equally significant. Instead, each case should receive a transparent classification based on available evidence.

A practical classification system could include:

ClassificationMeaningIdentifiedClearly explained by aircraft, astronomy, weather, satellites or another known cause.Probably identifiedEvidence strongly favours a conventional explanation, although minor uncertainties remain.Insufficient informationToo little information exists to investigate properly.UnresolvedSufficient evidence exists, but no conventional explanation currently fits all observations.Hoax or fabricationEvidence demonstrates deliberate falsification or misrepresentation.

Publishing every investigated case—including those explained by ordinary causes—would improve public confidence more than releasing only unusual incidents. Readers could see that investigators apply the same standards regardless of the outcome.

## Building transparency instead of mystery

One of the greatest weaknesses of many historical UFO collections is that they preserve conclusions but not the underlying evidence. A Comorian archive should reverse that approach.

Each published investigation should include:

* The original witness report.

<div class="content-enhancement content-enhancement--metric" markdown="1">

* A timeline of the investigation.
* Weather data consulted.
* Aviation checks performed.
* Astronomical comparisons.
* Satellite comparisons where available.
* Photographic analysis if images exist.
* The final classification.
* A record of any later corrections.

</div>

Publishing the investigative process allows future researchers to reassess cases if improved satellite databases, astronomical software or image-analysis techniques become available.

## What should count as a high-value case?

Most reports are likely to have conventional explanations. A small number may justify more extensive investigation because they contain multiple independent lines of evidence.

Cases deserving priority review would include:


<div class="content-enhancement content-enhancement--insight-grid" markdown="1">

* Independent witnesses observing the same event from different locations.
* Simultaneous photographs or videos from separate observers.
* Reports coinciding with aviation or meteorological records that exclude obvious explanations.
* Events documented with precise timing and location.
* Observations lasting long enough for careful description rather than brief flashes of light.

</div>

Conversely, anonymous social media claims without dates, locations or original files should remain archived but not treated as strong evidence.

## Protecting data quality over time

Because Comoros has relatively few publicly documented aerial anomaly reports, the archive should prioritise quality rather than quantity. Every record should preserve the original evidence, even if the event is later explained.

Investigators should avoid deleting solved cases. Instead, they should retain both the original report and the explanation. This creates a valuable reference library showing which kinds of observations are repeatedly mistaken for satellites, planets, aircraft or atmospheric effects.

Maintaining version histories is equally important. If new evidence changes a case from "unresolved" to "identified", both the original assessment and the revised conclusion should remain publicly visible.

## How this fits within the wider Comoros project

Given the current lack of a well-established national UFO chronology, the most valuable contribution Comoros could make is not the creation of dramatic case files but the establishment of a trustworthy reporting process. Such a system would naturally support future work on national sighting chronology, comparisons between Grande Comore, Anjouan and Mohéli, and assessments of whether reports represent ordinary aerial phenomena, unresolved observations or cases explained through later investigation.

A transparent archive built on standardised witness interviews, aviation records, meteorological data and published classifications would provide a far stronger foundation than isolated anecdotes. Even if very few reports ultimately remained unexplained, the resulting archive would still serve aviation safety, preserve historical records and demonstrate that unusual observations had been evaluated using consistent, evidence-based methods rather than speculation.

  sections.forEach(function (section) {
    if (section.getAttribute('data-ebay-localized-init') === '1') return;
    section.setAttribute('data-ebay-localized-init', '1');
    var available = availableMarkets(section);
    var marketId = defaultMarket;
    if (window.PhoenixAffiliateLocation && window.PhoenixAffiliateLocation.inferMarket) {
      marketId = window.PhoenixAffiliateLocation.inferMarket(available, {
        storageKey: 'phoenix-ebay-market',
        defaultMarket: defaultMarket
      });
    } else if (available.indexOf(defaultMarket)< 0) {
      marketId = available[0] || defaultMarket;
    }
    var select = section.querySelector('[data-ebay-market-select]');
    if (select) {
      select.addEventListener('change', function () {
        applyMarket(section, select.value, true);
      });
    }
    var trigger = section.querySelector('[data-ebay-market-trigger]');
    var menu = section.querySelector('[data-ebay-market-menu]');
    if (trigger && menu) {
      trigger.addEventListener('click', function (event) {
        event.stopPropagation();
        var expanded = trigger.getAttribute('aria-expanded') === 'true';
        menu.hidden = expanded;
        trigger.setAttribute('aria-expanded', expanded ? 'false' : 'true');
        var picker = trigger.closest('.fr-ebay-market-picker');
        if (picker) picker.classList.toggle('fr-ebay-market-picker--open', !expanded);
      });
      Array.prototype.slice.call(menu.querySelectorAll('[data-ebay-market-option]')).forEach(function (button) {
        button.addEventListener('click', function (event) {
          event.stopPropagation();
          applyMarket(section, button.getAttribute('data-ebay-market-option'), true);
        });
      });
      document.addEventListener('click', function () { closeMenu(section); });
    }
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]')).forEach(function (button) {
      button.addEventListener('click', function () {
        applyMarket(section, button.getAttribute('data-ebay-market-button'), true);
      });
    });
    applyMarket(section, marketId, false);
  });
