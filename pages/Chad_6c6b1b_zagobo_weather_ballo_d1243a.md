## Introduction

The Zagobo incident of July 2024 is the clearest documented UFO-related case in Chad precisely because it did **not** remain unexplained. What initially appeared to villagers to be a mysterious red-lit object falling from the sky was recovered, examined and publicly identified as a **Graw meteorological radiosonde** carried by a weather balloon. Unlike many UFO reports that rely only on witness testimony or distant lights, this case involved physical recovery of the object, official identification and a technical explanation consistent with both the evidence and the witnesses' descriptions.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.alwihdainfo.com/Tchad-l-ASECNA-rassure-sur-l-innocuite-du-ballon-meteorologique-tombe-a-Zagobo_a133685.html" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: alwihdainfo.com">[Alwihda Info]</a><span class="citation-popover" role="note"><span class="citation-popover-source">alwihdainfo.com</span><span class="citation-popover-title">Alwihda Info Tchad : l’ASECNA rassure sur l’innocuité du ballon météorologique tombé à Zagobo</span><span class="citation-popover-snippet">Alwihda Info Tchad : l’ASECNA rassure sur l’innocuité du ballon météorologique tombé à Zagobo</span></span></span>

## The night of the reported descent

During the evening of **4 July 2024**, residents of Zagobo, in the Dogou sub-prefecture of Tandjilé-Ouest Province, reported seeing a bright object descending into farmland behind their village. Witnesses consistently described an object displaying a conspicuous red light that could be seen from some distance, causing understandable concern among local residents unfamiliar with the equipment.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.alwihdainfo.com/tchad-un-engin-spatial-non-identifie-s-ecrase-dans-un-champ-a-zagobo-a133645/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: alwihdainfo.com">[Alwihda Info]</a><span class="citation-popover" role="note"><span class="citation-popover-source">alwihdainfo.com</span><span class="citation-popover-snippet">Open source on alwihdainfo.com.</span></span></span>

According to local reporting, the object struck the ground at around **10 p.m.** The prefect of Tandjilé-Ouest, General Doud Souleymane Ousmane, travelled to the location, supervised recovery of the device and arranged for it to be transported for examination. At this early stage, journalists described it simply as an unidentified flying object because its identity had not yet been established.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.alwihdainfo.com/tchad-un-engin-spatial-non-identifie-s-ecrase-dans-un-champ-a-zagobo-a133645/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: alwihdainfo.com">[Alwihda Info]</a><span class="citation-popover" role="note"><span class="citation-popover-source">alwihdainfo.com</span><span class="citation-popover-snippet">Open source on alwihdainfo.com.</span></span></span>

This distinction is important. "Unidentified" accurately reflected the situation immediately after discovery. It did not imply that the object was extraterrestrial or beyond ordinary explanation.

## How the radiosonde was identified

Following recovery, officials identified the device as a **Graw radiosonde**, a lightweight meteorological instrument designed to collect upper-atmosphere observations while suspended beneath a hydrogen-filled weather balloon. Chad's branch of the Agency for Air Navigation Safety in Africa and Madagascar (ASECNA) publicly confirmed that the recovered equipment formed part of routine atmospheric observations and posed no danger to the public.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.alwihdainfo.com/Tchad-l-ASECNA-rassure-sur-l-innocuite-du-ballon-meteorologique-tombe-a-Zagobo_a133685.html" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: alwihdainfo.com">[Alwihda Info]</a><span class="citation-popover" role="note"><span class="citation-popover-source">alwihdainfo.com</span><span class="citation-popover-title">Alwihda Info Tchad : l’ASECNA rassure sur l’innocuité du ballon météorologique tombé à Zagobo</span><span class="citation-popover-snippet">Alwihda Info Tchad : l’ASECNA rassure sur l’innocuité du ballon météorologique tombé à Zagobo</span></span></span>

ASECNA explained that the equipment performs standard radiosonde measurements during ascent, including:


<div class="content-enhancement content-enhancement--metric" markdown="1">

* Air temperature
* Atmospheric pressure
* Relative humidity
* Wind conditions
* Position data transmitted back to meteorological stations

</div>

When the balloon reaches very high altitude, it expands until it bursts. The instrument package then falls back to Earth, sometimes landing many kilometres from its launch location because strong upper-level winds carry it across long distances.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.alwihdainfo.com/Tchad-l-ASECNA-rassure-sur-l-innocuite-du-ballon-meteorologique-tombe-a-Zagobo_a133685.html" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: alwihdainfo.com">[alwihdainfo.com]</a><span class="citation-popover" role="note"><span class="citation-popover-source">alwihdainfo.com</span><span class="citation-popover-title">Alwihda Info Tchad : l’ASECNA rassure sur l’innocuité du ballon météorologique tombé à Zagobo</span><span class="citation-popover-snippet">Alwihda Info Tchad : l’ASECNA rassure sur l’innocuité du ballon météorologique tombé à Zagobo</span></span></span>

International weather agencies launch thousands of radiosondes every day as part of the World Meteorological Organization's upper-air observing network, which provides essential data for weather forecasting and climate monitoring.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://wmo.int/activities/global-observing-system-gos/global-observing-system-gos" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: wmo.int">[wmo.int]</a><span class="citation-popover" role="note"><span class="citation-popover-source">wmo.int</span><span class="citation-popover-title">World Meteorological Organization Global Observing System (GOS</span><span class="citation-popover-snippet">World Meteorological Organization Global Observing System (GOS</span></span></span>

## Why the explanation matched the witnesses

One reason the Zagobo report attracted attention was that the eyewitness descriptions sounded dramatic. However, the identified equipment accounts for nearly every reported observation.

The **red light** was not inconsistent with a radiosonde. Weather-balloon payloads may include lights or reflective components that make them easier to locate or identify during flight or recovery. At night, an unfamiliar illuminated instrument descending under a balloon—or after balloon failure—can appear highly unusual to observers on the ground.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.alwihdainfo.com/Tchad-l-ASECNA-rassure-sur-l-innocuite-du-ballon-meteorologique-tombe-a-Zagobo_a133685.html" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: alwihdainfo.com">[Alwihda Info]</a><span class="citation-popover" role="note"><span class="citation-popover-source">alwihdainfo.com</span><span class="citation-popover-title">Alwihda Info Tchad : l’ASECNA rassure sur l’innocuité du ballon météorologique tombé à Zagobo</span><span class="citation-popover-snippet">Alwihda Info Tchad : l’ASECNA rassure sur l’innocuité du ballon météorologique tombé à Zagobo</span></span></span>

Likewise, the reported descent into fields fits the normal end of a radiosonde flight. A weather balloon ascends until decreasing atmospheric pressure causes it to rupture. The instrument package then returns to the surface, drifting with high-altitude winds before landing, often far from its launch site.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.alwihdainfo.com/Tchad-l-ASECNA-rassure-sur-l-innocuite-du-ballon-meteorologique-tombe-a-Zagobo_a133685.html" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: alwihdainfo.com">[alwihdainfo.com]</a><span class="citation-popover" role="note"><span class="citation-popover-source">alwihdainfo.com</span><span class="citation-popover-title">Alwihda Info Tchad : l’ASECNA rassure sur l’innocuité du ballon météorologique tombé à Zagobo</span><span class="citation-popover-snippet">Alwihda Info Tchad : l’ASECNA rassure sur l’innocuité du ballon météorologique tombé à Zagobo</span></span></span>

The object was also described as an unfamiliar technical device after recovery rather than as a conventional aircraft or meteorite. That observation became an important clue, since the recovered equipment matched commercially manufactured meteorological hardware rather than any unknown technology.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.alwihdainfo.com/Tchad-l-ASECNA-rassure-sur-l-innocuite-du-ballon-meteorologique-tombe-a-Zagobo_a133685.html" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: alwihdainfo.com">[Alwihda Info]</a><span class="citation-popover" role="note"><span class="citation-popover-source">alwihdainfo.com</span><span class="citation-popover-title">Alwihda Info Tchad : l’ASECNA rassure sur l’innocuité du ballon météorologique tombé à Zagobo</span><span class="citation-popover-snippet">Alwihda Info Tchad : l’ASECNA rassure sur l’innocuité du ballon météorologique tombé à Zagobo</span></span></span>

## Why this case is unusually strong evidence

Most reported UFO incidents remain difficult to evaluate because investigators lack one or more key pieces of evidence:


<div class="content-enhancement content-enhancement--insight-grid" markdown="1">

* The object is never recovered.
* Images are poor or ambiguous.
* Witness accounts conflict.
* No official technical examination follows.

    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-option]')).forEach(function (button) {
      button.setAttribute('aria-selected', button.getAttribute('data-ebay-market-option') === marketId ? 'true' : 'false');
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]')).forEach(function (button) {
      var active = button.getAttribute('data-ebay-market-button') === marketId;
      button.setAttribute('aria-pressed', active ? 'true' : 'false');
    });
    section.setAttribute('data-ebay-selected-market', marketId);
    if (persist) {
      try { if (window.localStorage) localStorage.setItem('phoenix-ebay-market', marketId); } catch (err) {}
    }
    closeMenu(section);
  }
  sections.forEach(function (section) {
    if (section.getAttribute('data-ebay-localized-init') === '1') return;
    section.setAttribute('data-ebay-localized-init', '1');
    var available = availableMarkets(section);
    var marketId = defaultMarket;
    if (window.PhoenixAffiliateLocation && window.PhoenixAffiliateLocation.inferMarket) {
      marketId = window.PhoenixAffiliateLocation.inferMarket(available, {
        storageKey: 'phoenix-ebay-market',
        defaultMarket: defaultMarket
      });
    } else if (available.indexOf(defaultMarket)< 0) {
      marketId = available[0] || defaultMarket;
    }
    var select = section.querySelector('[data-ebay-market-select]');
    if (select) {
      select.addEventListener('change', function () {
        applyMarket(section, select.value, true);
      });
    }
    var trigger = section.querySelector('[data-ebay-market-trigger]');
    var menu = section.querySelector('[data-ebay-market-menu]');
    if (trigger && menu) {
      trigger.addEventListener('click', function (event) {
        event.stopPropagation();
        var expanded = trigger.getAttribute('aria-expanded') === 'true';
        menu.hidden = expanded;
        trigger.setAttribute('aria-expanded', expanded ? 'false' : 'true');
        var picker = trigger.closest('.fr-ebay-market-picker');
        if (picker) picker.classList.toggle('fr-ebay-market-picker--open', !expanded);
      });
      Array.prototype.slice.call(menu.querySelectorAll('[data-ebay-market-option]')).forEach(function (button) {
        button.addEventListener('click', function (event) {
          event.stopPropagation();
          applyMarket(section, button.getAttribute('data-ebay-market-option'), true);
        });
      });
      document.addEventListener('click', function () { closeMenu(section); });
    }
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]')).forEach(function (button) {
      button.addEventListener('click', function () {
        applyMarket(section, button.getAttribute('data-ebay-market-button'), true);
      });
    });
    applyMarket(section, marketId, false);
  });
})();
