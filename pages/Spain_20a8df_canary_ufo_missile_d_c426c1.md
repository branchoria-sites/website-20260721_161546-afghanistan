## Introduction

The Canary Islands produced some of [Spain]({{ 'what-spains-ufo-files-actually-reveal/' | relative_url }})’s most dramatic UFO reports during the 1970s, with enormous glowing clouds, expanding rings of light and brilliant luminous structures seen simultaneously from several islands and ships at sea. At first glance, these displays appeared unlike conventional aircraft or astronomical objects. However, subsequent technical analysis has increasingly pointed towards a different explanation for several of the best-known cases: high-altitude missile launches over the Atlantic, whose exhaust plumes were illuminated by the Sun long after sunset for observers on the ground. This interpretation does not explain every witness statement, but it does account for the large-scale luminous clouds and changing geometric forms that made the events appear extraordinary. The Canary Islands therefore provide one of Spain’s clearest examples of how an impressive aerial phenomenon can be both genuinely spectacular and ultimately compatible with known aerospace physics.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://bibliotecavirtual.defensa.gob.es/BVMDefensa/exp_ovni/es/consulta/registro.do?control=BMDB20160069082" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: bibliotecavirtual.defensa.gob.es">[Biblioteca Virtual Defensa]</a><span class="citation-popover" role="note"><span class="citation-popover-source">bibliotecavirtual.defensa.gob.es</span><span class="citation-popover-snippet">Open source on gob.es.</span></span></span>

## The 22 June 1976 incident

The best-known case occurred on 22 June 1976 and remains one of the largest files in Spain's declassified military archive. The Spanish Air Force devoted more than 100 pages to witness interviews, diagrams, maps and technical analysis before the file was declassified in 1994.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://bibliotecavirtual.defensa.gob.es/BVMDefensa/exp_ovni/es/consulta/registro.do?control=BMDB20160069082" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: bibliotecavirtual.defensa.gob.es">[Biblioteca Virtual Defensa]</a><span class="citation-popover" role="note"><span class="citation-popover-source">bibliotecavirtual.defensa.gob.es</span><span class="citation-popover-snippet">Open source on gob.es.</span></span></span>

Observers reported:


<div class="content-enhancement content-enhancement--insight-grid" markdown="1">

* A brilliant luminous sphere visible across several islands.
* An expanding transparent or bluish structure.
* A prolonged display lasting roughly forty minutes.
* Observations from both land and sea.

</div>

The official investigators classified the event as an unidentified aerial phenomenon because they could not establish a definitive explanation from the evidence available at the time. Importantly, "unidentified" reflected the limits of the investigation rather than a conclusion that an extraordinary craft had been demonstrated.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://bibliotecavirtual.defensa.gob.es/BVMDefensa/exp_ovni/es/consulta/registro.do?control=BMDB20160069082" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: bibliotecavirtual.defensa.gob.es">[Biblioteca Virtual Defensa]</a><span class="citation-popover" role="note"><span class="citation-popover-source">bibliotecavirtual.defensa.gob.es</span><span class="citation-popover-snippet">Open source on gob.es.</span></span></span>

## Why missile exhaust can create giant glowing clouds

The missile explanation rests on a well-understood physical mechanism rather than on similarities in appearance alone.

When a ballistic missile climbs into the upper atmosphere after sunset, its exhaust gases expand rapidly in the near vacuum. Instead of forming a narrow trail, they can spread into an enormous cloud hundreds of kilometres across.

Several factors then combine to produce striking visual effects:


<div class="content-enhancement content-enhancement--insight-grid" markdown="1">

* **Sunlight at high altitude:** Although observers below are in darkness, the exhaust cloud may still be illuminated by the Sun.
* **Rapid expansion:** Low atmospheric pressure allows the plume to grow into circular or umbrella-shaped forms.
* **Changing viewing angle:** As the missile climbs, perspective changes create apparent rings, spirals and expanding spheres.
* **Ice crystals and combustion products:** These scatter sunlight into brilliant white, blue or iridescent colours.

</div>

To people unfamiliar with these effects, the result can resemble an enormous glowing object that appears to change shape while remaining almost stationary. Because the cloud is extremely distant, observers also tend to underestimate its altitude while overestimating its apparent size. This combination makes the display seem unlike ordinary aircraft behaviour even though it follows known atmospheric physics.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://ufotransparency.com/international/files/es" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: ufotransparency.com">[UFO Transparency]</a><span class="citation-popover" role="note"><span class="citation-popover-source">ufotransparency.com</span><span class="citation-popover-title">UFO Transparency Spain files · 01 Disclosures · UFO Transparency</span><span class="citation-popover-snippet">UFO Transparency Spain files · 01 Disclosures · UFO Transparency</span></span></span>

## Why distance and scale were so easily misjudged

Human perception struggles to estimate the distance of isolated lights against a dark sky.

Without nearby reference points, witnesses naturally assume that a bright object is relatively close. If the object is actually hundreds of kilometres away, small changes in viewing geometry can appear as dramatic movement.

For the Canary Islands displays this produced several common perceptual effects:


<div class="content-enhancement content-enhancement--insight-grid" markdown="1">

* A distant expanding cloud appeared to become an enormous solid object.
* Slow atmospheric evolution resembled controlled manoeuvring.
* Bright central regions looked like self-luminous craft.
* Large translucent clouds appeared as transparent domes or spheres.

</div>

Because many observers saw essentially the same luminous structure from different islands, their accounts reinforced one another. The consistency demonstrates that an unusual phenomenon was genuinely present, but it does not by itself distinguish between an exotic craft and a very large atmospheric event. Understanding the viewing geometry is therefore critical when evaluating the reports.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://bibliotecavirtual.defensa.gob.es/BVMDefensa/exp_ovni/es/consulta/registro.do?control=BMDB20160069082" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: bibliotecavirtual.defensa.gob.es">[Biblioteca Virtual Defensa]</a><span class="citation-popover" role="note"><span class="citation-popover-source">bibliotecavirtual.defensa.gob.es</span><span class="citation-popover-snippet">Open source on gob.es.</span></span></span>

## The 5 March 1979 display and the missile hypothesis

Another widely reported Canary Islands event occurred on 5 March 1979. Witnesses described an immense iridescent cloud and bright luminous object visible across the islands and parts of north-west Africa. ## Why the missile explanation is persuasive—but not complete

The missile interpretation has gained support because it explains several otherwise puzzling characteristics simultaneously:

* Long duration.

## What the Canary Islands cases contribute to Spain's UFO record

Within Spain's broader UFO history, the Canary Islands incidents are valuable not because they provide compelling evidence of extraterrestrial technology, but because they illustrate how extraordinary atmospheric events can generate sincere, detailed and sometimes conflicting witness reports.

The declassified military files show that investigators took these incidents seriously, collecting testimony from numerous observers and preserving extensive documentation rather than dismissing the reports outright. Later aerospace knowledge, particularly regarding high-altitude missile exhaust illuminated by the Sun, has provided a coherent explanation for many of the spectacular luminous clouds that originally appeared inexplicable. Yet the files also remind readers that an official designation of "unidentified" often reflects incomplete evidence rather than confirmation of an extraordinary cause.

    params.push('mkevt=1');
    params.push('mkcid=1');
    params.push('toolid=' + encodeURIComponent(cfg.tool_id || '10001'));
    if (reference) params.push('customid=' + encodeURIComponent(reference).slice(0, 256));
    return url + joiner + params.join('&');
  }
  function domainLabel(marketId) {
    var cfg = markets[marketId] || markets[defaultMarket] || {};
    return cfg.domain_label || 'eBay';
  }
  function flagClass(marketId) {
    return 'fr-ebay-market-flag fr-ebay-market-flag--' + String(marketId || '').toLowerCase().replace(/_/g, '-').replace(/[^a-z0-9-]+/g, '');
  }
  function closeMenu(section) {
    var menu = section.querySelector('[data-ebay-market-menu]');
    var trigger = section.querySelector('[data-ebay-market-trigger]');
    var picker = section.querySelector('.fr-ebay-market-picker');
    if (menu) menu.hidden = true;
    if (trigger) trigger.setAttribute('aria-expanded', 'false');
    if (picker) picker.classList.remove('fr-ebay-market-picker--open');
  }
  function availableMarkets(section) {
    var select = section.querySelector('[data-ebay-market-select]');
    if (select) {
      return Array.prototype.slice.call(select.options)
        .map(function (option) { return option.value; })
        .filter(function (marketId) { return !!markets[marketId]; });
    }
    return Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]'))
      .map(function (button) { return button.getAttribute('data-ebay-market-button'); })
      .filter(function (marketId) { return !!markets[marketId]; });
  }
  function applyMarket(section, marketId, persist) {
    var available = availableMarkets(section);
    if (available.indexOf(marketId)< 0) marketId = available[0] || defaultMarket;
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-localized-link]')).forEach(function (link) {
      var query = link.getAttribute('data-ebay-query') || '';
      var reference = link.getAttribute('data-ebay-reference') || '';
      link.setAttribute('href', buildUrl(query, reference, marketId));
    });
    var select = section.querySelector('[data-ebay-market-select]');
    if (select && available.indexOf(marketId) >= 0) select.value = marketId;
    var selectedText = marketId;
    if (select && select.selectedIndex >= 0) selectedText = select.options[select.selectedIndex].text;
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-selected-market-label]')).forEach(function (label) {
      label.textContent = selectedText;
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-selected-market-flag], [data-ebay-trigger-market-flag]')).forEach(function (flag) {
      flag.className = flagClass(marketId);
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-trigger-market-label]')).forEach(function (label) {
      label.textContent = selectedText;
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-domain-label]')).forEach(function (label) {
      label.textContent = domainLabel(marketId);
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-option]')).forEach(function (button) {
      button.setAttribute('aria-selected', button.getAttribute('data-ebay-market-option') === marketId ? 'true' : 'false');
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]')).forEach(function (button) {
      var active = button.getAttribute('data-ebay-market-button') === marketId;
      button.setAttribute('aria-pressed', active ? 'true' : 'false');
    });
    section.setAttribute('data-ebay-selected-market', marketId);
    if (persist) {
      try { if (window.localStorage) localStorage.setItem('phoenix-ebay-market', marketId); } catch (err) {}
    }
    closeMenu(section);
  }
  sections.forEach(function (section) {
    if (section.getAttribute('data-ebay-localized-init') === '1') return;
    section.setAttribute('data-ebay-localized-init', '1');
    var available = availableMarkets(section);
    var marketId = defaultMarket;
    if (window.PhoenixAffiliateLocation && window.PhoenixAffiliateLocation.inferMarket) {
      marketId = window.PhoenixAffiliateLocation.inferMarket(available, {
        storageKey: 'phoenix-ebay-market',
        defaultMarket: defaultMarket
      });
    } else if (available.indexOf(defaultMarket)< 0) {
      marketId = available[0] || defaultMarket;
    }
    var select = section.querySelector('[data-ebay-market-select]');
    if (select) {
      select.addEventListener('change', function () {
        applyMarket(section, select.value, true);
      });
    }
    var trigger = section.querySelector('[data-ebay-market-trigger]');
    var menu = section.querySelector('[data-ebay-market-menu]');
    if (trigger && menu) {
      trigger.addEventListener('click', function (event) {
        event.stopPropagation();
        var expanded = trigger.getAttribute('aria-expanded') === 'true';
        menu.hidden = expanded;
        trigger.setAttribute('aria-expanded', expanded ? 'false' : 'true');
        var picker = trigger.closest('.fr-ebay-market-picker');
        if (picker) picker.classList.toggle('fr-ebay-market-picker--open', !expanded);
      });
      Array.prototype.slice.call(menu.querySelectorAll('[data-ebay-market-option]')).forEach(function (button) {
        button.addEventListener('click', function (event) {
          event.stopPropagation();
          applyMarket(section, button.getAttribute('data-ebay-market-option'), true);
        });
      });
      document.addEventListener('click', function () { closeMenu(section); });
    }
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]')).forEach(function (button) {
      button.addEventListener('click', function () {
        applyMarket(section, button.getAttribute('data-ebay-market-button'), true);
      });
    });
    applyMarket(section, marketId, false);
  });
})();
